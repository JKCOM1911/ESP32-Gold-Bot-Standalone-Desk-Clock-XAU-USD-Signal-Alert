# ESP32 Gold Bot — Standalone Desk Clock & XAU/USD Signal Alert

นาฬิกาตั้งโต๊ะอัจฉริยะและระบบเฝ้าติดตามราคาทองคำ (`XAU/USD` / `GOLD#`) แบบ **Standalone 24/7** ที่ทำงานบนบอร์ด **ESP32** ร่วมกับจอ **OLED SSD1306** และแจ้งเตือนเข้า **Telegram Bot** โดยตรงโดยไม่ต้องเปิดคอมพิวเตอร์ทิ้งไว้

---

## ✨ ฟีเจอร์หลัก (Key Features)

* **ราคาทองคำวิ่งสดแบบเรียลไทม์:** ผสานราคาฐาน `XAU/USD` จาก Twelve Data เข้ากับความเร็วอัปเดตของ `PAXGUSDT` จาก Binance พร้อมปรับค่าชดเชยส่วนต่างโบรกเกอร์ (`Broker Price Offset`) ได้
* **วิเคราะห์เทรนด์และจุดเข้า-ออก (M30 + M15):**
  * ดูแนวโน้มหลักบนไทม์เฟรม **M30** (`EMA 50` / `EMA 200`)
  * หาจังหวะย่อตัวเข้าซื้อ/ขายบนไทม์เฟรม **M15** (`RSI Envelope` + `EMA 14/28`) พร้อมคำนวณ `Entry`, `SL` และ `TP1–TP4` จาก `ATR`
* **แจ้งเตือนเข้า Telegram อัตโนมัติ:** ส่งข้อความแจ้งเตือนเมื่อบอร์ดออนไลน์, เมื่อเกิดสัญญาณ `BUY` / `SELL` และเมื่อราคาชน `TP1` หรือ `SL`
* **หน้าจอ OLED ครบทุกสถานะ:** แสดงวันที่และเวลาไทย (`NTP UTC+7`), ราคาทองสด, สถานะเทรนด์/สัญญาณ, Pop-up แจ้งเตือนจุดเข้า-ออก และโหมดหน้าหุ่นยนต์กระพริบตา (`Cute Face Animation`)
* **ระบบกันข่าวแรง (News Guard):** หยุดส่งสัญญาณชั่วคราวในช่วงเวลาข่าวผันผวนสูงหรือแท่งเทียนกระชากแรงผิดปกติ
* **ตั้งค่า Wi-Fi ง่ายผ่านมือถือ:** มี Captive Portal (`ESP32_Clock_Setup` ➔ `192.168.4.1`) สำหรับเลือก Wi-Fi และปรับค่า `Offset` โดยไม่ต้องแก้โค้ดซ้ำ

## 🚀 วิธีใช้งาน (How to Use)

1. ใส่ **Twelve Data API Key**, **Telegram Bot Token** และ **Telegram Chat ID** ในส่วนตั้งค่าของโค้ด แล้วอัปโหลดลงบอร์ด ESP32
2. หากยังไม่เคยตั้งค่า Wi-Fi ให้เชื่อมต่อฮอตสปอต **`ESP32_Clock_Setup`** แล้วเปิดเบราว์เซอร์ไปที่ **`192.168.4.1`** เพื่อตั้งค่า Wi-Fi และ `Broker Price Offset`
3. กดปุ่ม **`BOOT`** 1 ครั้งเพื่อเปิด/ปิดโหมดหน้าหุ่นยนต์ หรือกดค้าง **3 วินาที** เพื่อรีเซ็ตการตั้งค่า Wi-Fi
